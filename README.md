# SCOA

SCOA é um Sistema de Controle de Oficinas Automotivas

## Tecnologias

- Java 21
- Sprint Boot 4.1.1
- Postgresql
- Flyway Migration

## Funcionalidades

- Emissão de orçamentos
- Criação de serviços
- Cadastro e gecenciamento de funcionários
- Controle de estoque
- Registro de saída de materiais
